# Portfolio Design

## Theme

Retro Digital Interface

Inspired by:

- LED displays
- Dot matrix typography
- Space interfaces
- Minimal futuristic installations

---

## Colors

Palette: "Pure signal" — black, white, and one red accent. Mission-control
styling: white does the structural work (borders, corner brackets, numbers);
red is reserved for live signals (rec dot, cursor, primary action, one
highlighted readout).

Dark (default) / Light — tokens live in `src/app/globals.css`.

| Token       | Dark      | Light     |
| ----------- | --------- | --------- |
| Background  | #000000   | #FFFFFF   |
| Panel       | #0B0B0B   | #F4F4F4   |
| Line        | #222222   | #DCDCDC   |
| Text        | #FFFFFF   | #000000   |
| Muted       | #8F8F8F   | #6B6B6B   |
| Signal red  | #FF2B2B   | #E00000   |
| Red tint    | #3A0B0B   | #FFE3E3   |

The light theme uses a darker red so it passes WCAG AA on white.
The theme follows the system setting until the visitor picks one in the nav.

Large display typography.

Dot matrix headings.

## Animations

Slow.

Subtle.

Purposeful.

## User Experience

The website should feel immersive.

Scrolling should reveal information naturally.

Everything should breathe.

Avoid clutter.

The content should be the focus.
